# README Editing Policy

- Do not use `README.md` as the default destination for new documentation.
- Prefer explicitly named documents in the location appropriate to their role under the [documentation policy](../../policy/documentation.md) for living documentation.
- Use the Git-ignored `.agents/handoff/` directory or Issues for short-lived discussion documents.
- Edit an existing README only when:
  - the requested change specifically concerns the README.
  - command/link update.
  - the README contains a section explicitly intended to be kept current.
- When editing such a section, limit the change to that section unless the user
  explicitly requests broader README changes.
