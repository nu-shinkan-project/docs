# 一時ドキュメントの運用

ユーザがアクセス可能な位置への文書ファイルの出力を要求した場合，もしくは，それが適当な場合は，メインリポジトリの`.agents/handoff`ディレクトリを利用します．

一時ドキュメントを作成する際は，`.agents/handoff`ディレクトリが存在しなければ，作成してください．

`.agents/handoff`の典型的な利用例は次のとおりです．ただし，この例は利用方法を制限するものではありません．

- 実装計画書のやり取り
- 調査報告書の出力先
- 比較検討のファイル形式での成果物
