# デプロイとタグ

このプロジェクトでは、`main` の最新コミットがそのままデプロイされるわけではない。

デプロイ対象は Git タグで管理している。

- `release`: 本番環境へデプロイするコミット
- `staging`: ステージング環境へデプロイするコミット

そのため、`main` の先頭と、実際に各環境へデプロイされているコミットは異なる場合がある。

デプロイするコミットを変更したい場合は、対象となるタグを別のコミットへ付け替える。

タグを付け替えるときは、GitHub の **Actions** タブから、タグの付け替えを行う workflow を探して実行する。

たとえば、本番環境で問題が発生した場合には、`release` タグを以前正常に動作していたコミットへ戻すことで、そのコミットを再び本番環境へデプロイできる。

このように、Git の履歴そのものを変更することなく、デプロイ対象だけを切り替えられるようになっている。
